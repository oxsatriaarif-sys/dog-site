The manual.

Every command, every flag, and what each one refuses to do.

Install

brew install dog
curl -fsSL https://dog.sh/install.sh | sh

Or grab a static binary from GitHub releases. No runtime, no daemon, no key storage.

Reading

dog

dog <object>

Show the contents of an object. A wallet is its balances; a position is its collateral and health. dog prints objects, not tables — which is why everything else can read them.

dog wallet

ls

ls <context>

List the objects in the current context. ls never paginates silently: if there is more than one screen, it says so.

ls positions

grep

… | grep <field>

Filter a stream by a field you name. grep works on any field any command emits, because every command speaks the same object grammar.

dog wallet | grep dust

sort

… | sort <field>

Order by a named field. There is no default order — an unordered list prints in chain order and says so.

ls positions | sort pnl

diff

diff <object> --since <t>

Compare two states of the same object. diff shows what changed, when it changed, and which signature did it.

diff wallet --since 7d

scan

scan <scope>

Walk state and print what is found. scan reads; it never writes, and it stops politely when you press Ctrl-C.

scan approvals

Action

sweep

… | sweep

Close what is piped in: dust tokens, empty accounts, stale approvals. Returns the rent. sweep refuses anything that was not explicitly piped into it.

dog wallet | grep dust | sweep

hiss

hiss

Show what is dangerous: open approvals, suspicious signatures. hiss is read-only by design — pointing at a thing is not the same as touching it.

hiss | sort age

nine

nine

Roll back the last action, and say plainly what cannot be undone. When a swap has settled, nine tells you so instead of pretending.

nine

Time

nap

nap <task> --in <t> | --every <t>

Defer a task, once or on a repeat. A napped task runs with the same permissions you gave it when you typed it — no more.

nap rent-check --every 30d

wake

wake "<pipe>" <condition>

Execute when a condition is met, whether or not you are there. wake shows you the exact pipe it will run before arming, and waits for your confirmation.

wake "ls positions | grep MNGO | close" --below 0.92
wake "dog wallet | export" --every 24h

watch

watch <target> <condition>

Monitor and notify, doing nothing else. Free while the terminal is open. watch cannot act, even if you ask it to — that is what wake is for.

watch MNGO/USDC --below 0.92

purr

purr

Status of background tasks: what is armed and what it waits for. purr also disarms, with --disarm <id>.

purr
purr --disarm w-042

Composition

paw

… | paw <name>

Save a pipe as a named script. The script is stored verbatim — exactly the text that flowed through the pipe, nothing inferred.

dog wallet | grep dust | sweep | paw dust-sweep

fetch

fetch @<handle>/<script>

Load someone else's script by handle and name. fetch prints the whole script before running it, and asks once.

fetch @nine/rent-check

Output

chart

… | chart

Render a stream instead of listing it. chart works on anything with a numeric field, because it receives objects like everyone else.

diff wallet --since 7d | chart

export

… | export

Dump a stream in a form other tools can read. JSON by default; CSV with --csv.

dog wallet | export

Errors & refusals

Errors speak in the first person

dog did not do this

nine cannot undo: the swap settled

hiss found nothing to bark at

No exit codes as personality. The error names itself, states what happened, and stops.

What dog will not do

  • No key storage — keys stay in your wallet, always.
  • No autonomous action — every acting task was typed by you first.
  • No advice — dog reports state; it does not have opinions about it.
  • No commands that don't pipe — if it can't compose, it doesn't ship.
