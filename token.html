$DOG

$DOG — collateral, not governance theater.

The token exists for one reason: guards must post collateral that loses value when the network fails. Everything else it does is a side effect.

Why collateral

Skin in the game

Guards post $DOG and lose part of it for a task they took and missed.

Aligned by construction

Collateral must lose value along with the network it secures — that is the whole design.

Not a gate

Everything local is free. You never need the token to read, filter, or sign.
