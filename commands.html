commands

Every command, and what it refuses to do.

One object type, one grammar over it. Every command reads a stream and writes a stream, so any two of them compose with a pipe.

READ

dog

dog <object>

Show the contents of an object.

dog wallet
try it ↗

ls

ls <context>

List the objects in the current context.

ls positions
try it ↗

grep

… | grep <field>

Filter a stream by a field you name.

dog wallet | grep dust
try it ↗

sort

… | sort <field>

Order by a named field. There is no default order.

ls positions | sort pnl
try it ↗

diff

diff <object> --since <t>

Compare two states of the same object.

diff wallet --since 7d
try it ↗

scan

scan <scope>

Walk state and print what is found.

scan approvals
try it ↗

ACT

sweep

… | sweep

Close what is piped in: dust tokens, empty accounts, stale approvals. Returns the rent.

dog wallet | grep dust | sweep
try it ↗

hiss

hiss

Show what is dangerous: open approvals, suspicious signatures.

hiss | sort age
try it ↗

nine

nine

Roll back the last action, and say plainly what cannot be undone.

nine
try it ↗

GUARD

nap

nap <task> --in <t> | --every <t>

Defer a task, once or on a repeat.

nap rent-check --every 30d
try it ↗

wake

wake "<pipe>" <condition>

Execute when a condition is met, whether or not you are there.

wake "ls positions | grep MNGO | close" --below 0.92
try it ↗

watch

watch <target> <condition>

Monitor and notify, doing nothing else. Free while the terminal is open.

watch MNGO/USDC --below 0.92
try it ↗

purr

purr

Status of background tasks: what is armed and what it waits for.

purr
try it ↗

COMPOSE

paw

… | paw <name>

Save a pipe as a named script.

dog wallet | grep dust | sweep | paw dust-sweep
try it ↗

fetch

fetch @<handle>/<script>

Load someone else's script by handle and name.

fetch @nine/rent-check
try it ↗

OUTPUT

chart

… | chart

Render a stream instead of listing it.

diff wallet --since 7d | chart
try it ↗

export

… | export

Dump a stream in a form other tools can read.

dog wallet | export
try it ↗

UTILITY

pspsps

pspsps

Link a wallet. The only command that is just for fun. The fun is functional.

pspsps
try it ↗

Errors speak in the first person: dog did not do this. Full grammar in docs.html.
