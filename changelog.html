changelog

Every change, in the open.

dog is versioned like the tool it is. Here is what changed, what broke, and what got faster.

v0.9.22026-08-19

Wake by block height

  • Added: chart --spark for one-line sparklines
  • Changed: wake intents now expire by block height, not wall clock
  • Fixed: purr no longer truncates long script names

v0.9.02026-07-28

$DOG collateral

  • Added: export --csv
  • Added: guard network accepts collateral in one asset: $DOG
  • Changed: sweep refunds rent in the same tx (no claim step)
  • Fixed: diff --since handles timezone-less timestamps

v0.8.32026-07-02

Severity first

  • Fixed: nap --every drifts no more than one slot
  • Changed: hiss sorts by severity by default — the only default in dog, and it is a warning, not advice.

v0.7.02026-06-10

Read before run

  • Added: fetch prints source before running
  • Added: paw --list shows command counts
  • Fixed: nine now refuses loudly instead of silently on settled swaps

v0.5.02026-05-04

First public release

  • Added: first public release. read, act, guard, compose — the whole grammar.
